## 概要

モバイルデバイス（スマホ、タブレット、ラップトップ）のよくあるトラブルと対処法を理解する。Domain 5（Troubleshooting）の範囲。

---

## 1. バッテリーの問題

### 症状と原因

| 症状 | 原因 |
|------|------|
| 充電が持たない | バッテリーの劣化 / アプリの電力消費 / 電波が弱い環境で常に信号を探している |
| バッテリーが膨張 | バッテリー内部にガスが溜まっている → デバイスが変形する |
| 急速に減る | バックグラウンドアプリ / Wi-Fi・Bluetooth・GPSが常にON |

### 対処法
- バッテリー統計を確認（Settings → Battery）で電力消費が多いアプリを特定
- 使っていない機能をOFFにする（Wi-Fi、Bluetooth、GPS、位置情報）
- 電波が悪い場所では **機内モード** をONにする
- バッテリー膨張 → **即使用中止、交換必須**（火災リスクあり）
- 膨張バッテリーを開けたり刺したりしない → 有害ガス・発火の危険

---

## 2. 画面の破損

### 対処法
- 交換前に必ず **バックアップ** を取る
- ガラスだけの交換はできない → ガラスとディスプレイが一体化しているため、**ディスプレイごと交換**
- 割れた画面は鋭利 → 指で触らない
- スクリーンプロテクターやガラステープで一時的に保護可能

---

## 3. 充電の問題

### チェック手順
1. **充電ポート** — 内部にゴミや異物がないか確認
2. **ケーブル** — 別の正常なケーブルで試す（断線の可能性）
3. **電源アダプター** — マルチメーターで出力を確認
4. **コンセント** — 壁のコンセント自体に問題がないか確認

### よくある原因
- 充電ポート内のゴミ・異物
- ケーブルの断線（頻繁に動かすと摩耗する）
- 電源アダプターの故障

---

## 4. 液体損傷（★今日の問題に関連）

### LCI（Liquid Contact Indicator）
- デバイス内部に液体接触インジケーターがある
- 充電ポートやSIMスロットの内部に設置
- 液体に触れると色が変わる → 修理時に最初にチェックされる

### 液体をこぼした時の対処法（★暗記必須）

```
1. 即座に電源OFF
2. 充電器を接続しない
3. ケースを外す
4. SIM・バッテリー等の取り外せるパーツを外す
5. 風通しの良い場所で乾燥させる
6. 可能ならデシカント（乾燥剤）と一緒に袋に入れる
7. 最低24時間は触らない
8. 24時間後、乾いていたら電源ONを試す
```

### ★ やってはいけないこと
- ❌ 米に入れる → 実際にはほとんど効果なし（水を吸収する力が弱い）
- ❌ 加熱する / オーブンに入れる
- ❌ 電源を入れてみる
- ❌ 充電器を繋ぐ
- ❌ 振ったり動かしたりする

> **試験ポイント:** 「米に入れる」は不正解の選択肢として頻出。正しいのはデシカント（乾燥剤）。

## 5. 過熱（Overheating）

### 原因
- 直射日光 / 高温環境
- CPU負荷の高いアプリ
- 充電中にアプリを使用
- ダッシュボードに放置

### 対処法
- 直射日光を避ける
- バッテリーレポートでCPU負荷の高いアプリを確認
- 不要なアプリを終了
- 過熱すると **デバイスが自動でシャットダウン** する（保護機能）

---

## 6. 画面が真っ暗 / 応答なし（Unresponsive Screen）

### リセット方法

| デバイス | 方法 |
|---------|------|
| iPhone | 電源ボタン長押し → スライドで電源OFF → 再度電源ON |
| iPhone（フリーズ時） | 電源 + ホーム or 音量ボタンを10秒長押し → 強制リセット |
| Android | メーカーにより異なる。バッテリー取り外し or 電源+音量ボタンの組み合わせ |

→ 自分のデバイスのリセット手順は事前に確認しておく

---

## 7. インターフェースの損傷

### USBポートの損傷
- 充電できない / データ転送できない
- 充電ケーブルの乱暴な扱いが原因になることが多い
- USBポートはシステムボードに直付け → **システムボードごと交換が必要**（モジュラーではない）

### 症状
- 充電が断続的
- ケーブルを特定の角度にしないと充電しない

---

## 8. ワイヤレス接続の問題

### セルラー（携帯回線）
- 基地局からの距離が影響
- 建物の中 → 外に出ると改善する場合がある

### Wi-Fi
- アクセスポイントからの距離
- 周辺のAPとのチャンネル干渉
- 対策: チャンネルや周波数帯を変更する

---

## 9. マルウェア

### 兆候
- 見覚えのないアプリがインストールされている
- データ使用量が異常に多い
- 特定アプリのCPU使用率が異常に高い
- バッテリーが異常に早く減る

### 対処法
- モバイル向けアンチマルウェア / アンチウイルスソフトを使用
- 不審なアプリをアンインストール

---

## 10. カーソルドリフト（Cursor Drift / Ghost Touch）

### 症状
- 触っていないのに画面が勝手に反応する
- アプリが勝手に起動する

### 原因
- デジタイザーの不具合
- 画面の汚れや水滴
- ハードウェアの故障

### 対処法
- 画面を清掃
- デバイスを再起動
- 改善しない場合はデジタイザー / ディスプレイの交換

## 暗記チェックリスト

- [ ] バッテリー膨張 → 即使用中止、火災リスク
- [ ] 液体損傷 → 電源OFF → 充電しない → デシカントで乾燥 → 24時間放置
- [ ] 米は効果なし（試験で不正解の選択肢）
- [ ] LCI = 液体接触インジケーター（充電ポート / SIMスロット内）
- [ ] 充電問題 → ポート確認 → ケーブル交換 → アダプター確認
- [ ] USBポート損傷 → システムボードごと交換が必要
- [ ] 過熱 → 直射日光避ける、CPU負荷高いアプリ確認
- [ ] 画面破損 → ガラスだけ交換不可、ディスプレイごと交換
- [ ] カーソルドリフト → デジタイザーの不具合
